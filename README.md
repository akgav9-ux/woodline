# WOODLINE

Mobile-first демонстрационный сайт мебельной студии.

## Возможности
- Адаптивная главная и каталог из шести категорий.
- Пошаговый калькулятор типа мебели, размеров, фасадов и материалов.
- Проверка обязательных полей и согласия на связь.
- Подготовка заявки, открытие WhatsApp и копирование текста.
- Демонстрационные интерьерные фотографии загружаются с Unsplash.

## Перед запуском для реальной компании
- Заменить фото и примеры на реальные работы с разрешением владельца.
- Добавить контакты компании и прямые ссылки WhatsApp/Telegram.
- Подключить серверное сохранение заявок и уведомления.
- Согласовать прайс и формулу предварительной оценки. Сейчас сайт не показывает выдуманную цену.
- Реализовать админ-панель для проектов, цен и заявок.

Сейчас это демонстрационный MVP, не CRM и не готовая production-система.
